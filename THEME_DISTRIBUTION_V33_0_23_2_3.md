# Ticarti Theme Distribution

Current model:
- dev.ticarti.com is documentation and developer guidance only for themes.
- Ticarti does not collect third-party theme ZIP files on the developer site.
- Theme developers may sell/distribute themes independently.
- Merchants install a theme ZIP from their own Admin > Themes workflow.
- Existing theme ZIP parser/security validation remains the installation gate.
- A future Ticarti Theme Store submission/review flow can be introduced separately if/when a marketplace is launched.
- The already-created ThemeDeveloperRelease database table is intentionally left dormant; no destructive migration is performed.
