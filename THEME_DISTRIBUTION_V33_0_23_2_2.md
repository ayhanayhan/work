# Theme Distribution v33.0.23.2.2

- Merchant theme ZIP upload remains in the merchant/admin theme workflow.
- Ticarti system/theme catalog management remains in Super Admin.
- Third-party theme developers submit theme ZIP packages through authenticated dev.ticarti.com/themes.
- Public developer documentation does not expose a raw theme-upload API contract.
- The backend console endpoint remains authenticated with DeveloperAuthGuard and is an implementation detail of Developer Console.
- Submitted versions remain staged until Super Admin approval; the live theme is not replaced before approval.
